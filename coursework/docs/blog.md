# Блог / заметки


Здесь будут заметки о проектах, технологиях, идеях и решениях, которые появляются по ходу работы и обучения.


# Как создавался этот сайт


Изначально идея была сделать не просто обычный персональный сайт с набором страниц и информации о себе.

Хотелось создать что-то более похожее на личную историю — место, где можно показать не только результат, но и процесс создания.


## Создание сайта


Основой проекта стал MkDocs, который позволил собрать структуру сайта, страницы и документацию в одном месте.

Дальше появилась идея сделать оформление не как у обычного документа, а ближе к интерактивному проекту.

Хотелось сохранить простоту редактирования, но добавить больше индивидуальности.


## Нереализованные идеи


Во время разработки появилось много идей, которые пока остались в планах.


### Анимации


Одной из идей была более глубокая анимация интерфейса:

- интерактивные переходы между разделами;
- дополнительные эффекты появления элементов;
- более динамичная главная страница;
- развитие эффекта Matrix.


Некоторые элементы уже были реализованы, но часть идей пока осталась как направление для дальнейшего развития.


### Музыкальное сопровождение


Ещё одна идея — добавить фоновое музыкальное сопровождение.

Хотелось сделать не просто обычный звук на странице, а аккуратную систему:

- включение и отключение музыки пользователем;
- разные варианты для разных разделов;
- атмосферное оформление главной страницы.


Пока от этой идеи отказались, чтобы сайт оставался удобным и не раздражал пользователя.


### Дополнительные функции


В дальнейшем можно добавить:

- больше интерактивных элементов;
- отдельные страницы для проектов;
- визуализацию процесса разработки;
- дополнительные материалы по технологиям.
