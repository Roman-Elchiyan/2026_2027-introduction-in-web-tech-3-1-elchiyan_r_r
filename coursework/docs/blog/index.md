# Блог / заметки

Здесь будут появляться заметки о разработке сайта, технических экспериментах и идеях, которые не вошли в основные разделы.

---

## Заметка №1. Идеи, которые не вошли в первую версию сайта

При создании сайта было много идей, которые не вошли в первую рабочую версию.

Изначально хотелось сделать не просто набор страниц, а более интерактивный проект.

Одной из основных идей была анимация в стиле «Матрицы» — динамический фон с бегущими символами, который создавал бы атмосферу сайта.

Также рассматривались дополнительные функции:

- музыкальное сопровождение отдельных разделов;
- интерактивные переходы между страницами;
- дополнительные визуальные эффекты;
- анимированные элементы интерфейса;
- небольшие скрытые сценарии внутри сайта.

Часть этих идей пока осталась на этапе концепции, потому что сначала было важнее сделать стабильную структуру сайта и собрать основные разделы.

Сейчас сайт развивается как личный проект, где объединяются история, рабочие проекты и технические эксперименты.

В дальнейшем этот раздел будет использоваться для заметок о новых функциях, разработке и изменениях проекта.
